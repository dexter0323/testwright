# TestWright

TestWright is a Moon-managed Playwright test harness for multiple apps and APIs. Tests are committed TypeScript and run deterministically. OpenCode helps explore apps and author/debug those tests using app manifests, skills, CLI, and MCP browser tools.

## Start here

- [Getting started](getting-started.md) — install the pinned toolchain and run the first suite.
- [Architecture](architecture.md) — how Moon projects, apps, and Playwright projects fit together.
- [Writing tests](writing-tests.md) — UI, API, and journey conventions.
- [App manifests](app-manifests.md) — point agents to app source, APIs, and targets.
- [OpenCode workflow](opencode-workflow.md) — describe a flow and turn it into a verified test.
- [Logs and debugging](logs-and-debugging.md) — find per-app diagnostics and Playwright artifacts.
